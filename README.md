# DCE-4DNeRF: Spatio-Temporal Neural Representations for Tumor-Aware Neoadjuvant Chemotherapy Response Prediction

**This repository is maintained by the authors of the corresponding research work.**

## Abstract

Predicting the pathological complete response (pCR) to neoadjuvant chemotherapy is critical for personalized breast cancer treatment. Existing MRI-based approaches, however, face challenges due to nonuniform temporal acquisition intervals in dynamic contrast-enhanced MRI (DCE-MRI) and interference from irrelevant anatomical regions.

To address these limitations, we propose a unified framework consisting of DCE-4DNeRF, which constructs a spatio-temporally continuous radiance field from discretely acquired DCE-MRI sequences to mitigate temporal inconsistency, and TAR-Net, a tumor-aware network that leverages longitudinal intensity positional encoding to selectively capture tumor-relevant information for accurate pCR prediction without manual tumor segmentation.

Extensive experiments demonstrate that our framework achieves strong predictive performance and robustness, providing a practical paradigm for continuous modeling of DCE-MRI and therapy response analysis.
